Make a Siri shortcut ("Hey Siri, run Pon")
  1. Open the Shortcuts app → + → Add Action → search Open URLs.
  2. Paste the bot's link (tap "Show links" below, long-press a link, Copy).
  3. Name the shortcut, e.g. Run Pon. Say "Hey Siri, Run Pon" → GitHub opens → tap Submit.
  4. Optional: share the shortcut to your Home Screen for a one-tap button.
